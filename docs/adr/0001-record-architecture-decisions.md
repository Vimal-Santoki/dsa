# 1. Record architecture decisions

Date: 2026-01-23

## Status

Accepted

## Context

We need to record architectural decisions made in this project so that we don't restart discussions on things we have already decided, and so that new team members can understand the context of the decisions.

## Decision

We will use Architecture Decision Records (ADRs) to track key architectural modifications.

We will use the [Markdown Architectural Decision Records](https://github.com/joelparkerhenderson/architecture-decision-record) format.

## Consequences

- We will have a history of decisions.
- We will arguably write better software because we will force ourselves to think through the consequences of our decisions.
- New contributors will be able to understand the "why" behind the code faster.
