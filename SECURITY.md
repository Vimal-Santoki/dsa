# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you find a vulnerability, please do NOT open a public issue.

Instead, please email **security@example.com**.

We will verify your report and respond within 48 hours.
